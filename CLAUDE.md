# Vercel MCP — regras de uso

- Só operar no projeto Vercel explicitamente indicado pelo usuário na tarefa em questão. Nunca listar, inspecionar ou alterar outros projetos que apareçam na conta Vercel conectada, mesmo que pareçam relacionados.
- Se não estiver claro qual é o projeto correto, perguntar ao usuário antes de usar qualquer ferramenta do MCP da Vercel.
- Qualquer ação de escrita via MCP da Vercel (deploy, alterar variáveis de ambiente, alterar configurações do projeto, domínios, remover/criar recursos, etc.) exige autorização explícita do usuário antes de ser executada. Descrever a ação pretendida e aguardar confirmação — nunca executar de forma proativa.
- Ações somente leitura (listar deployments, ver logs, ver status) não exigem autorização prévia, desde que restritas ao projeto autorizado.
