# MCPs de infraestrutura (Vercel, Supabase, Railway etc.) — regras de uso

- Só operar no projeto/recurso explicitamente indicado pelo usuário na tarefa em questão, em qualquer um desses MCPs. Nunca listar, inspecionar ou alterar outros projetos que apareçam na conta conectada, mesmo que pareçam relacionados.
- Se não estiver claro qual é o projeto correto, perguntar ao usuário antes de usar qualquer ferramenta desses MCPs.
- Qualquer ação de escrita (deploy, alterar variáveis de ambiente/segredos, alterar configurações do projeto, schema ou dados do banco, domínios, remover/criar recursos, etc.) exige autorização explícita do usuário antes de ser executada. Descrever a ação pretendida e aguardar confirmação — nunca executar de forma proativa.
- Ações somente leitura (listar deployments, ver logs, ver status, ver schema) não exigem autorização prévia, desde que restritas ao projeto autorizado.
